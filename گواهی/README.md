# آرشیو مستقل گواهی‌ها

این پوشه صرفاً برای نگهداری، بازیابی و مدیریت نسخه‌های نامه‌ها و گواهی‌های کاری ایجاد شده است.

- این پوشه بخشی از معماری، محصول، مستندات یا زنجیره اجرایی پروژه Future AI / Palang Footprint نیست.
- نسخه ۰۱، نسخه مبنا است و نباید بازنویسی یا جایگزین شود.
- نسخه‌های شماره‌دار قبلی محفوظ می‌مانند؛ هیچ نسخه‌ای بدون اجازه صریح کاربر بازنویسی نمی‌شود.
- به دلیل عمومی بودن مخزن، اطلاعات حساس مانند شماره ملی در فایل‌های این پوشه پوشانده شده‌اند.
- متن نسخه اولیه در این آرشیو همان متن تثبیت‌شده در مکالمه است؛ بازیابی آن از یک فایل اصلی مستقل تأیید نشده است.
