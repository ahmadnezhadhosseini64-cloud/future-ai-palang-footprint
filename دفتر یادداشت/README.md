# دفتر یادداشت

این پوشه فقط آرشیو شماره‌دار ورودی‌ها و خروجی‌های مورد درخواست مالک است و کاربرد اجرایی/معماری ندارد.

- N01: نخستین رونوشت ثبت‌شده از ورودی مالک.
- N02: رونوشت پاسخ و نتیجهٔ اجرای این نوبت.
- N02 به بعد: هر ورودی/خروجی بعدی با شمارهٔ یکتا و به ترتیب افزایشی.

قاعده: متن هر یادداشت عیناً نگهداری می‌شود؛ اصلاح یا بازنویسی فقط با دستور صریح مالک و با حفظ نسخهٔ قبلی مجاز است.
