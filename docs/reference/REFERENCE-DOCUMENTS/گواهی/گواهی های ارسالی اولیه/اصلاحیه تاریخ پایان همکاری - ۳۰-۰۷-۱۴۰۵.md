# سند اصلاحیه — تاریخ پایان همکاری در صندوق گواهی

- تاریخ ثبت اصلاحیه: ۲۰۲۶-۱۰-۱۹
- پروژه: صندوق گواهی (`CERTIFICATE-INBOX`)
- نقطهٔ ادامه: `CERTIFICATE-INBOX-0.0-THIRD-2026-10-19-001`
- وضعیت پروژه: `OPEN / باز`

## دستور اصلاح

به درخواست کاربر، تاریخ پایان از `۳۱/۰۵/۱۴۰۵` به `۳۰/۰۷/۱۴۰۵` تغییر داده شد و تاریخ جدید به‌عنوان **تاریخ پایان همکاری** درج می‌شود.

## تغییرات اعمال‌شده در فایل‌های اصلی

1. «گواهی اول اولیه شماره ۱.txt»: عبارت اشتغال «تا کنون» به بازهٔ پایان‌یافته در `۳۰/۰۷/۱۴۰۵` تغییر کرد؛ بازهٔ سوابق نیز با همین تاریخ پایان می‌یابد.
2. «گواهی چکیده پیوست شماره ۱.txt»: وضعیت به «پایان همکاری در تاریخ ۳۰/۰۷/۱۴۰۵» تغییر کرد؛ پایان سوابق و پایان سمت آخر نیز به همان تاریخ به‌روزرسانی شد.
3. مدت همکاری از `۰۱/۰۹/۱۳۹۹` تا `۳۰/۰۷/۱۴۰۵` نزدیک به شش سال است؛ اختلاف تقویمی ۵ سال و ۱۰ ماه و ۲۹ روز است.

## وضعیت شواهد

- دو فایل اصلی اصلاح‌شده از مخزن بازخوانی شدند و تاریخ جدید در هر دو دیده شد.
- سند مرجع کامل قبلی و README در این مرحله هنوز اصلاحیهٔ جدید را در متن خود ندارند؛ این سند مستقل برای حفظ مسیر تغییر ثبت می‌شود.
- بافر و حافظهٔ پایدار در این عملیات ثبت یا تأیید نشده‌اند.
- نسخه‌های پیشین از تاریخچهٔ Git قابل بازیابی‌اند.

## اقدام ادامه

هنگام بازگشت، اصلاحیه را با سند مرجع کامل نقطهٔ سوم و نمایهٔ README پیوند بده؛ سپس هر چهار فایل را از مخزن بازخوانی و تطبیق کن. پروژه فقط با فرمان صریح «این پروژه رو ببند» بسته می‌شود.
