## 10. اصل نهایی
PRESERVE → IDENTIFY → VALIDATE → DEDUPLICATE → RECONCILE → REGISTER → READ-BACK → MATCH → VERIFY → CONTINUE
(حفظ → شناسایی → اعتبارسنجی → حذف تکرار با حفظ تاریخچه → تطبیق → ثبت → بازخوانی → تطبیق محتوا → تأیید → ادامه)

INCOMPLETE ≠ LOST؛ PENDING ≠ BURIED؛ FOUND ≠ RETRIEVED ≠ REVIVED ≠ VERIFIED.
هیچ ادعایی بدون شاهد نیست. تاریخچه حذف نمی‌شود، وضعیت مقصدها مخلوط نمی‌شود، و هیچ صفی صرفاً به‌خاطر محدودیت بسته نمی‌شود.
