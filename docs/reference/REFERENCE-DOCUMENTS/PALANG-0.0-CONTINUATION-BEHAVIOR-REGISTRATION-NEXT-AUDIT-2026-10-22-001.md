## 8. مقصدها
- Repository: پس از commit و read-back قابل تأیید.
- Buffer: UNVERIFIED تا آزمون نوشتن و بازیابی.
- Persistent Memory: UNVERIFIED تا اثبات مستقل؛ این سند ادعای نوشتن در حافظهٔ پایدار نمی‌کند.
- Library خارج از مخزن: UNVERIFIED تا بررسی مستقل.
- Dropbox: OPEN / NOT VERIFIED تا اتصال، نوشتن و بازیابی.
