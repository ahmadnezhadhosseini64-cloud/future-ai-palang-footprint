## 1. Core decision / تصمیم اصلی
«ثبت کن» یک دستور ساده برای نگه‌داشتن متن نیست. از این پس باید به‌صورت پیش‌فرض یک فرمان سطح‌بالای ثبت تلقی شود و سیستم خودش همه تعهدات لازم را انتخاب و اجرا/پیگیری کند؛ کاربر نباید برای هر بار استفاده، مقصدهایی مانند مخزن، حافظه پایدار، پوشه سند مرجع یا جایگذاری معماری را جداگانه نام ببرد.

## 2. Default workflow / چرخه پیش‌فرض
PRESERVE → CLASSIFY → CAPTURE PROVENANCE → CAPTURE LINEAGE → ASSIGN/RETAIN ID → BUILD REFERENCE ARTIFACT WHEN QUALIFIED → ARCHITECTURAL PLACEMENT → WRITE TO REQUIRED AVAILABLE PERSISTENCE SURFACES → READ-BACK → MATCH → VERIFY → RECONCILE → DERIVE STATUS → REGISTER/CONNECT → CLOSE OR KEEP OPEN.

حفظ → دسته‌بندی → ثبت منشأ → ثبت تبار → حفظ/اختصاص شناسه → ساخت سند مرجع در صورت واجد شرایط بودن → جایگذاری معماری → ثبت در سطوح ماندگاری لازم و در دسترس → بازخوانی → تطبیق → تأیید → همسان‌سازی/رفع مغایرت → استخراج وضعیت از شواهد → ثبت/اتصال → بستن یا باز نگه‌داشتن تعهدات.

4. Persistent Memory / حافظه پایدار، با شواهد مستقل همان لایه.
5. Architectural Placement / جایگذاری در Master / Child / Rahm یا لایه مربوط.
6. Lineage / زنجیره Previous → Current → Next (قبلی → جاری → بعدی).

«ثبت کن» یعنی این سطوح به‌صورت خودکار بررسی و مسیر لازم برای آنها انتخاب شود؛ نه اینکه موفقیت هر سطح بدون شواهد ادعا شود.

## 4. Reference Document rule / قاعده سند مرجع
اگر محتوا یک تولید ارزشمند، قاعده، تصمیم، کنترل یا معماری باشد، سیستم باید آن را به‌صورت سند مرجع کامل، یکپارچه و دارای هویت، نسخه، منشأ، شواهد، تبار، مسیر، وضعیت و بازیابی ایجاد و در Reference Documents Vault / مخزن اسناد مرجع قرار دهد.

## 5. No-extra-command principle / اصل بی‌نیازی از فرمان تکراری
پس از گفتن «ثبت کن»، کاربر لازم نیست دوباره بگوید: «در مخزن ثبت کن»، «در حافظه پایدار ثبت کن»، «سند مرجع بساز»، «در پوشه قرار بده»، «زنده‌اش کن»، «اجرایی‌اش کن» یا «مسیر بازیابی بده». این موارد، هرجا مرتبط و از نظر فنی قابل اجرا باشند، بخشی از مسیر پیش‌فرض ثبت هستند.

## 6. Evidence gate / دروازه شواهد
WRITE → READ-BACK → MATCH → VERIFY → RECONCILE → STATUS
ثبت/نوشتن واقعی → بازخوانی همان مورد از همان سطح → تطبیق → تأیید با شواهد → همسان‌سازی/رفع مغایرت → تعیین وضعیت.

شواهد یک سطح، ادعای سطح دیگر را نمی‌بندد. ثبت در Library / کتابخانه به‌تنهایی اثبات حافظه پایدار یا مخزن مرجع نیست؛ ثبت در مخزن نیز به‌تنهایی اثبات حافظه پایدار نیست؛ و سند معماری به‌تنهایی اثبات اجرای مستقل Runtime / زمان اجرا نیست.

## 7. Failure/recovery / شکست و بازیابی
PRESERVE STATE → RECORD BLOCKER → OPEN/PENDING → KEEP SAME ID → RETRY → READ-BACK → VERIFY → RECONCILE → PROMOTE.

حالت حفظ شود → مانع ثبت شود → وضعیت باز/در انتظار باقی بماند → همان شناسه حفظ شود → تلاش مجدد → بازخوانی → تأیید → همسان‌سازی → ارتقا پس از بسته‌شدن شواهد.

شکست نباید به از دست رفتن تبدیل شود. تلاش مجدد نباید شناسه تکراری بسازد. هر لایه مسدود باید با همان هویت، مانع و گام بعدی قابل بازیابی بماند.

## 8. Status semantics / معنای وضعیت‌ها
INCOMPLETE = ناقص؛ PENDING = در انتظار تکمیل/اثبات؛ BLOCKED = مسدود به‌علت نبود قابلیت/دسترسی لازم؛ REGISTERED = ثبت‌شده با شواهد همان سطح؛ VERIFIED = تأییدشده با شواهد کافی برای همان ادعا؛ ACTIVE / LIVING = فعال / زنده در محدوده شواهد؛ FINAL = نهایی فقط پس از بسته‌شدن تعهدات لازم.

گفتن «ثبت کن» یا «خوبه» به‌تنهایی هیچ وضعیت مثبت فنی را اثبات نمی‌کند.

## 9. Communication control / کنترل ارتباطی
هر شناسه، وضعیت، پروتکل یا اصطلاح فنی انگلیسی در پاسخ فارسی باید توضیح فارسی روشن نزدیک خود داشته باشد. کنترل Communication Identifier Explanation Check / کنترل بررسی توضیح فارسی شناسه‌ها و اصطلاحات ارتباطی، پیش از پاسخ اعمال می‌شود.

## 10. Hammer validation / اعتبارسنجی با چکش
چکش نشان می‌دهد منظور کاربر صرفاً «یادآوری یک ترجیح» نیست؛ هدف تبدیل «ثبت کن» به یک فرمان عملیاتی پیش‌فرض است که خودش تعهدات ثبت، سند مرجع، ماندگاری، جایگذاری معماری، شواهد، بازیابی و بازیابی آینده را انتخاب و دنبال می‌کند.

اصل سخت‌کننده:
AUTOMATIC ROUTING ≠ AUTOMATIC FABRICATION.
یعنی مسیر لازم باید خودکار انتخاب و اجرا/پیگیری شود، اما هیچ مرحله‌ای بدون شواهد واقعی انجام‌شده اعلام نمی‌شود.

آزمون‌های پذیرش: انتخاب خودکار همه سطوح لازم؛ بررسی خودکار واجد شرایط بودن سند مرجع؛ وضعیت مستقل مخزن و حافظه پایدار؛ ایجاد تعهد بازیابی برای شکست؛ حفظ همان شناسه در تلاش مجدد؛ جلوگیری از کپی خاموش؛ توضیح فارسی شناسه‌ها و وضعیت‌ها؛ و استخراج وضعیت نهایی فقط از شواهد.
