## Decision 3 — mirror evidence

A mirror is useful only when it is an independently controlled destination with byte-level read-back and recovery evidence. A second copy in the same control plane, or a library mirror whose exact bytes differ (including a trailing newline), is not proof of independent persistence or host recovery. Mirror registration is therefore supporting evidence, not a core gate. Do not schedule recurring mirror work without a concrete failure it prevents.
