## User intent preserved
The original Future AI / Palang Footprint project is the **MASTER**: it owns accepted rules, observed interaction/behavior patterns, source provenance, architecture lineage and the authoritative record. The newer initial-model project is the **RAHM**: a controlled, isolated growth and validation environment attached to the Master, not a parallel independent authority. A candidate becomes a **CHILD** only after tests and evidence pass and the Master explicitly accepts/promotes it.

## Required relationship
`MASTER → RAHM → OBSERVATION → HYPOTHESIS → TEST → EVIDENCE REVIEW → CHILD CANDIDATE → MASTER ACCEPT/REJECT/RETURN`

`MASTER ↔ RAHM` means versioned, traceable exchange of source-backed rules and test results; it does not authorize Rahm to overwrite the Master. `CHILD → MASTER` is a reviewed promotion proposal, never an automatic write.
