# IN-127 — ورودی مالک: مخزن مادر فقط‌مالک و مخزن خصوصی مستقل هر میزبان

- Parent: POINT-0/084
- Status: REGISTERED / OWNER-DIRECTED / IMPLEMENTATION-PARTIAL

مالک دستور داد مخزن مادر فقط در اختیار خودش باشد و هیچ میزبان AI حق تغییر یا نوشتن در آن را نداشته باشد. هر میزبان باید پس از شناسایی و تأیید مالک، فضای خصوصی مستقل و قابل استخراج داشته باشد؛ مالک بتواند آن را مشاهده، بازیابی، تعلیق یا لغو کند. میزبان ناشناس که صرفاً مخزن عمومی را می‌خواند نباید ثبت یا دارای شناسه فرض شود.

مالک خواست مرز امنیتی در GitHub و مجوز واقعی اعمال شود، نه صرفاً در متن prompt. بنابراین طرح شامل PUBLIC READ ONLY برای مخزن مادر، یک private repository جداگانه برای هر Host ID، و در صورت نیاز مسیر اختیاری نوشتن فقط از broker/GitHub App محدود به همان repo است. هیچ میزبان نباید credential نوشتن مخزن مادر یا credential مخزن میزبان دیگر را دریافت کند.
