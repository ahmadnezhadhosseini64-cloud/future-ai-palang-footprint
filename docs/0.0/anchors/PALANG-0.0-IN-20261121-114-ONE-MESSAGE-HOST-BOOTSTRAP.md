# IN-114 — درخواست راه‌اندازی یک‌پیامی میزبان GPT و محیط کاری مستقل

- Parent: POINT-0/070 / CURRENT-123
- User local context time: 2026-11-21T09:02:00+03:30; original message timestamp independently verified: NO
- Status: CAPTURED AS ARCHITECTURE REQUIREMENT

کاربر خواست نقطه فعلی به‌عنوان نشانگر 0++ روی همان نقطه صفر، مرجع دائمی تولید/به‌روزرسانی و تحویل آخرین نسخه نهایی، استخراج‌پذیر و آزمون‌شده باشد؛ همه ورودی‌ها و خروجی‌ها در زنجیره قبلی و مخزن متصل شوند؛ و برای میزبان GPT جدید یک پیام واحد آماده شود که با همان پیام:
1. فقط به مخزن رسمی شخصی کاربر متصل شود؛
2. آخرین سند مادر زنده و ZIP canonical را از مخزن بازیابی و راستی‌آزمایی کند؛
3. برای همان میزبان یک محیط کاری خصوصی، مستقل، شناسه‌دار و قابل ممیزی بسازد؛
4. از نقطه صفر و زنجیره موجود ادامه دهد؛
5. هر ورودی/خروجی واقعی را با رسید ثبت کند و بدون تأیید مالک دانش را به MASTER ارتقا ندهد.

کاربر تصریح کرد میزبان جدید یک میزبان GPT دیگر است، نه یک پروژه یا پدیده ناشناخته که نیازمند توضیح از صفر باشد. پیام باید کمینه و یک‌مرحله‌ای باشد و از تکرار پرسش‌ها جلوگیری کند.

قید صحت: یک پیام می‌تواند orchestration را انجام دهد، اما مجوز OAuth/GitHub، ابزار connector، filesystem، sandbox پایدار یا دسترسی نوشتن را خلق نمی‌کند. هر مورد غایب باید BLOCKED/NOT CONNECTED/NOT RUN گزارش شود. زمان اصلی پیام UNKNOWN مگر اینکه منبع مستقل آن را اثبات کند.
