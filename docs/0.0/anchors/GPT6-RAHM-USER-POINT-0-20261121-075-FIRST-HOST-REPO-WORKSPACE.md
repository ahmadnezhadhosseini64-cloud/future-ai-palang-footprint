## قرارداد دسترسی میزبان اول

- READ: دسترسی خواندن مخزن canonical از GitHub connector رسمی و احراز هویت‌شده.
- EXECUTE: محیط اجرای واقعی برای clone/checkout یا دریافت snapshot، اجرای اسکریپت‌ها و آزمون‌ها، بررسی diff و تولید رسید.
- WORKSPACE: محیط کاری متعلق به همان میزبان/جلسه؛ snapshot مرجع read-only و working tree جدا.
- WRITE: تغییر فایل‌ها در working tree و ثبت روی شاخهٔ اختصاصی میزبان، فقط در صورت وجود مجوز واقعی Contents:write و مجوز Push؛ سپس Pull Request به main.
- MAIN: هیچ push یا تغییر مستقیم و بی‌واسطه روی main، Release، secrets یا workflowهای حساس انجام نشود. ادغام PR طبق مجوز و کنترل مالک.
- AUTH: متن راهنما مجوز یا OAuth خلق نمی‌کند. مالک باید GitHub App/connector را از رابط رسمی محیط جدید به همین مخزن وصل کند. هرگز token/password در چت درخواست نشود.
- NO MAGIC HOST: این گفتگو نمی‌تواند یک نشست دیگر را از راه دور ایجاد یا احراز هویت کند. سند، نقش و کار را به میزبان اولی که مالک باز می‌کند تحویل می‌دهد.
