4. **Registration lifecycle:** دریافت → حفظ منشأ → طبقه‌بندی → IN/OUT → شناسه و نسخه → رویداد/لنگر → سند مادر و صف → نوشتن → بازخوانی → تطبیق → راستی‌آزمایی → تعیین وضعیت و اقدام بعدی.

10. **No redundant retest:** آزمون درست و بسته‌شده بی‌دلیل تکرار نمی‌شود؛ تکرار فقط با تغییر واقعی، نیاز جدید، خطا/رگرسیون یا شاهد متناقض.
11. **Privacy minimization:** دادهٔ حساس و غیرضروری در اسناد مخزن تکثیر نمی‌شود.
