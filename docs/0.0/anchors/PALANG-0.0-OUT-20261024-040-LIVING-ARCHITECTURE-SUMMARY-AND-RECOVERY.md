## Concise architecture / خلاصهٔ معماری
The architecture is a versioned, evidence-linked continuity system: Human ↔ AI Host ↔ HAIF. Every input, output, event, error, correction, and test is given a unique identity and linked to prior checkpoints and the living mother. New ideas begin as Child candidates, pass Rahm validation against evidence and acceptance criteria, and only then enter Master through additive versioning. The discovery engine finds and routes candidate changes; it does not itself prove unattended operation. The reference index and UTC-first Git commit anchors provide navigation and provenance. Export and cold-start recovery are the next acceptance gate.

این معماری یک سامانهٔ تداومِ نسخه‌دار و متکی بر شواهد است: انسان ↔ میزبان هوش مصنوعی ↔ HAIF. هر ورودی، خروجی، رویداد، خطا، اصلاح و آزمون شناسهٔ مستقل می‌گیرد و به نقاط قبلی و سند مادر زنده وصل می‌شود. پیشنهاد تازه ابتدا نوزاد (Child) است؛ در رحم (Rahm) با شواهد و معیارهای پذیرش اعتبارسنجی می‌شود؛ فقط پس از عبور وارد مستر (Master) می‌شود. تغییرات افزایشی‌اند و سابقه پاک نمی‌شود. موتور کشف تغییرات نامزد را پیدا و مسیریابی می‌کند، اما به‌تنهایی اجرای خودکار دائمی را اثبات نمی‌کند. فهرست مرجع و زمان UTC برگرفته از commit واقعی Git مسیر و منشأ را نگه می‌دارند. گام پذیرش بعدی، استخراج و بازیابی در زمینهٔ تازه است.
