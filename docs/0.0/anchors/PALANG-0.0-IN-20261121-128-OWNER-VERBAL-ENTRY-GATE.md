# IN-128 — درخواست ثبت گیت گفت‌وگویی ورود میزبان

کاربر خواست نقطهٔ تعامل جاری به ریشهٔ واحد POINT-0 متصل شود و روند ورود همهٔ میزبان‌های تازه ساده و دائمی گردد. شرط دقیق: پیام آماده‌شده نباید عبارت کد را افشا کند؛ میزبان باید نخست کد را از مالک بخواهد و تنها پس از پاسخ مالک ادامه دهد. همچنین کاربر پرسید آیا تنظیمات حفاظت مخزن را دستیار می‌تواند تغییر دهد.

قیود: کد صرفاً گیت گفت‌وگویی است؛ هیچ رمز حساب/توکن درخواست نمی‌شود. مخزن مادر PUBLIC READ و NO HOST WRITE باقی می‌ماند. NEXT-051 تنها صف فعال است.
