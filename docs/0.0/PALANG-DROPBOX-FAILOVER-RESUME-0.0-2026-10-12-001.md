## 2. آخرین وضعیت شناخته‌شده
- Dropbox: NOT CONNECTED / NOT VERIFIED — متصل نیست / تأیید نشده؛ شواهد اتصال موفق یا آزمون فایل وجود ندارد.
- آزمون نوشتن فایل: انجام‌نشده/تأییدنشده.
- READ-BACK (بازخوانی فایل از Dropbox): انجام‌نشده/تأییدنشده.
- MATCH (تطبیق محتوا): انجام‌نشده/تأییدنشده.
- Repository (مخزن): پروندهٔ اصلی این نقطه در مخزن موجود است؛ این پروندهٔ داخل پوشهٔ ۰.۰ نیز باید جداگانه پس از ایجاد بازخوانی و تطبیق شود.
- Buffer / Library (بافر / کتابخانه): ثبت مستقل این نقطه در این مقصدها تأیید نشده است.
- Persistent Memory (حافظهٔ پایدار): ثبت مستقل این نقطه تأیید نشده است.
- Offline copy (نسخهٔ آفلاین نزد کاربر): تأییدنشده تا وقتی کاربر واقعاً آن را ذخیره کند.

## 3. چه چیزی باقی مانده است؟
1. وضعیت اتصال Dropbox را از ابزار/رابط موجود بررسی کن؛ اگر اتصال فعال نیست یا ابزار آن را تأیید نمی‌کند، از کاربر بخواه اتصال و مجوزدهی را در رابط برنامه تکمیل کند.
2. پس از تأیید اتصال، یک فایل آزمایشی بی‌خطر با شناسه و نسخهٔ مشخص در Dropbox بنویس.
3. همان فایل را از Dropbox بازخوانی کن.
4. محتوای بازخوانی‌شده را با محتوای مورد انتظار تطبیق بده.
5. مسیر واقعی فایل، نتیجهٔ نوشتن، بازخوانی و تطبیق و هر خطای واقعی را ثبت کن.
6. تنها پس از موفقیت همهٔ گام‌ها وضعیت مسیر جایگزین را VERIFIED / تأییدشده اعلام کن.
7. جداگانه بررسی کن آیا فرایند خودکار واقعاً پیاده‌سازی و آزموده شده است؛ تا آن زمان مسیر را خودکار معرفی نکن.
