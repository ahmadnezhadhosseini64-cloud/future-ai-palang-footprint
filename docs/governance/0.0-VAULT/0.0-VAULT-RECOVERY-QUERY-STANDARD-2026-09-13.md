# 0.0 Vault Recovery / Query Standard

Production ID: 0.0V-QUERY-2026-09-13-001
Status: ACTIVE / LIVING

When asked to retrieve 0.0 history, the system should distinguish:
1. all 0.0 points;
2. open points;
3. unresolved points;
4. paused points;
5. points whose continuation was not completed;
6. points with unknown lineage;
7. independent paths;
8. branches and merges;
9. resolved points retained for provenance.

Never infer a missing 0.0 from absence in a current context. Use the Vault/registry and recovery sources. If a relationship cannot be established, report UNKNOWN rather than inventing continuity.

A retrieval result should preserve the point's stable identity, original timestamp/location context, last known state, continuation point, relationship status, and evidence/reconciliation state.
