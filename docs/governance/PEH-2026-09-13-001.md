## Purpose

`Palang Evidence Hammer (PEH)` is the evidence-hardening method used when the human invokes `چکش`. It is not merely “think more” and not merely “search more”. It is a structured adversarial pass that converts a plausible answer into a more defensible, uncertainty-aware conclusion.

## Core method

`Raw Data / Existing Context → Claims → Evidence vs Interpretation → Contradictions & Gaps → Competing Hypotheses → Explanatory Power → Counterattack → Revision → Re-test → Confidence / Uncertainty`

## Mandatory operations

1. **Separate data from narrative.** Identify what is directly given or evidenced versus what is already interpretation.
2. **Atomize claims.** Break the problem into testable claims rather than treating the topic as one assertion.
3. **Classify evidence.** Distinguish direct evidence, indirect evidence, inference, assumption, anecdote, and absence of evidence.
4. **Attack the first plausible explanation.** Search for assumptions, contradictions, failure modes, and alternative readings.
5. **Construct competing hypotheses.** Do not test only the favored explanation.
6. **Compare explanatory power.** Ask which hypothesis explains the observations with fewer unsupported assumptions.
7. **Preserve unresolved gaps.** “Unknown” must remain unknown; lack of explanation is not itself evidence for an extraordinary explanation.
8. **Re-test the revised conclusion.** The latest solution is itself subjected to an adversarial pass before closure.
9. **Calibrate the result.** State the conclusion at the strength justified by the evidence: e.g. `CONFIRMED`, `STRONG`, `PLAUSIBLE`, `WEAK`, or `INSUFFICIENT EVIDENCE`.

## Boundary

PEH does not expose or claim to reproduce private chain-of-thought. It specifies the observable, reusable reasoning protocol, decision criteria, evidence classes, and validation gates that can be documented and audited.

## Relationship to Palang Hammer

`Palang Hammer` remains the umbrella hardening command and completion standard already present in the Recovery Architecture. `PEH` is a named reasoning/evidence-hardening model under that umbrella. It does not replace the existing hammer standard; it operationalizes the analytical core when the task is to determine what is actually supported by available information.

## Non-goals

- No automatic creation of new architecture merely because a hammer was invoked.
- No equating “unresolved” with “extraordinary”.
- No treating search volume as evidence quality.
- No claiming persistence or verification without the applicable read-back evidence.
