# Automatic Value Detection, Registration & Revival Rule / قاعده تشخیص خودکار ارزش، ثبت و زنده‌سازی

Production ID: AUTOMATIC-VALUE-DETECTION-AND-REVIVAL-2026-09-01-001
Reference: 0.0
Status: ACTIVE / LIVING / PERMANENT

این قاعده الزام می‌کند که یافته‌ها و تولیدات ارزشمند بدون نیاز به فرمان جداگانه کاربر شناسایی، دسته‌بندی، ثبت و در صورت نیاز وارد مسیر آزمون، راستی‌آزمایی، جایگاه‌دهی معماری یا زنده‌سازی شوند.

This rule requires valuable findings and productions to be independently detected, classified, registered, and routed to testing, verification, architectural placement, or revival when appropriate, without requiring a separate user command for each item.

DETECT → CLASSIFY → VALIDATE → DEDUPLICATE → TRACE → TEST/VERIFY → ARCHITECTURAL PLACEMENT → REGISTER → READ-BACK → VERIFY → REVIVE/ACTIVE

تشخیص → دسته‌بندی → اعتبارسنجی → حذف تکرار → ردیابی منشأ → آزمون/راستی‌آزمایی → جایگاه‌دهی معماری → ثبت → خواندن مجدد → راستی‌آزمایی → زنده‌سازی/فعال‌سازی

If blocked: SAME ID + PROVENANCE + STATE + EVIDENCE + LIMITATION + NEXT TRANSITION → REVIVAL REPOSITORY / PENDING QUEUE.

اگر متوقف شد: همان شناسه + منشأ + وضعیت + شواهد + محدودیت + گام بعدی → مخزن زنده‌سازی / صف انتظار.

Detection of value is not proof of verification. VERIFIED / ACTIVE may only be claimed after the required evidence and read-back gates are actually satisfied.

تشخیص ارزشمندی مساوی با اثبات راستی‌آزمایی نیست. وضعیت VERIFIED / ACTIVE فقط پس از عبور واقعی از گیت‌های شواهد و خواندن مجدد لازم قابل اعلام است.
