## فارسی

### عنوان
قاعده ردیابی دوزبانه خروجی

### وضعیت
ACTIVE / LIVING / PERMANENT

### مرجع
0.0

### قاعده
در خروجی‌های گفت‌وگو، اصطلاحات فنی و مفاهیم انگلیسی باید برای فهم کاربر با معادل فارسی همراه شوند. برای یک اصطلاح یا عبارت کوتاه، معادل فارسی در پرانتز یا بلافاصله کنار آن می‌آید. برای زنجیره‌ها و مراحل، نسخه فارسی باید در خط زیرِ نسخه انگلیسی ارائه شود.

نمونه:

RETRIEVE → VALIDATE → RECONCILE → REGISTER → READ-BACK → VERIFY → ACTIVE

بازیابی → اعتبارسنجی → تطبیق/هم‌سنجی → ثبت → خواندن مجدد/بازخوانی → راستی‌آزمایی → فعال/زنده

این الزام فقط برای اسناد Repository نیست و خودِ خروجی مکالمه را نیز شامل می‌شود.

اگر این قاعده در یک اجرای خاص به‌علت محدودیت اجرا نشد، نقص باید قابل شناسایی و قابل اصلاح باقی بماند و نباید به‌عنوان اجرای کامل تلقی شود.

### اصل معماری
این قاعده بخشی از Traceability و قابل‌فهم‌بودن اجرای پروژه است و باید در زنجیره تولید، ثبت، بازیابی، زنده‌سازی و گزارش‌دهی رعایت شود.

## English

### Title
Bilingual Output Traceability Rule

### Status
ACTIVE / LIVING / PERMANENT

### Reference
0.0

### Rule
In conversational outputs, technical English terms and concepts must be accompanied by Persian equivalents so the user can understand what is being discussed. For a single term or short phrase, the Persian equivalent is provided in parentheses or immediately beside it. For chains and multi-step sequences, the Persian version is provided directly below the English version.

Example:

RETRIEVE → VALIDATE → RECONCILE → REGISTER → READ-BACK → VERIFY → ACTIVE

بازیابی → اعتبارسنجی → تطبیق/هم‌سنجی → ثبت → خواندن مجدد/بازخوانی → راستی‌آزمایی → فعال/زنده

This requirement applies not only to Repository documents but also to the conversational output itself.

If this rule cannot be followed in a particular execution because of an execution limitation, the gap must remain identifiable and correctable and must not be represented as fully executed.

### Architectural Principle
This rule is part of project traceability and execution comprehensibility and must be applied across production, registration, retrieval, revival, and reporting chains.
