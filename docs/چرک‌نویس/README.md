# چرک‌نویس سند مرجع تجمیع‌شده

وضعیت: OPEN / جمع‌آوری در حال انجام

این پوشه برای نگهداری موقت و ترتیبی بخش‌هایی است که احمد پلنگ در این گفتگو ارسال می‌کند. تا اعلام صریح «تمام شد»، هیچ تجمیع نهایی، بازنویسی یا ارتقایی انجام نمی‌شود.

هر بخش باید جداگانه و بدون حذف یا تغییر محتوای اصلی ثبت شود. پس از هر ثبت، باید محتوای ذخیره‌شده دوباره خوانده و با متن ارسالی تطبیق داده شود.

حذف محتویات این پوشه فقط پس از دستور صریح کاربر انجام می‌شود. حذف از شاخه جاری لزوماً تاریخچه Git را از بین نمی‌برد.

فعلاً این فایل فقط پوشه را ایجاد می‌کند؛ هنوز هیچ‌یک از بخش‌های سند در آن ثبت نشده است.
