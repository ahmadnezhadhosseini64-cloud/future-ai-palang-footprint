## 4. اصول اثبات

- UTC FIRST / ابتدا زمان UTC؛ سپس زمان متناظر تهران، با حفظ منبع و دقت واقعی.
- هر مرحله شاهد مستقل دارد؛ زمان آغاز، زمان ثبت مخزن، زمان تغییر و زمان راستی‌آزمایی یکی فرض نمی‌شوند.
- WRITE ≠ READ-BACK ≠ MATCH ≠ VERIFY — نوشتن، بازخوانی، تطبیق و تأیید چهار مرحلهٔ جدا هستند.
- CONNECTED ≠ TESTED ≠ VERIFIED — اتصال، آزمون و تأیید یکی نیستند.
- Repository success does not prove Dropbox, Buffer, Library, or Persistent Memory success.
- INCOMPLETE ≠ LOST — ناقص به معنی گم‌شده نیست.
- وضعیت کلی پس از این تلاش: IN PROGRESS / BLOCKED ON USER CONNECTION؛ نقطهٔ Dropbox همچنان OPEN / WAITING باقی می‌ماند.
