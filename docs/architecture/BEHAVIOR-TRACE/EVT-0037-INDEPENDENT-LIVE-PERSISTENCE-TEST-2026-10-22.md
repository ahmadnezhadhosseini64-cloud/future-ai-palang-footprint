- Library / کتابخانهٔ بیرونی: UNVERIFIED.
- Buffer / بافر: UNVERIFIED.
- Persistent Memory / حافظهٔ پایدار: UNVERIFIED.
- Dropbox / دراپ‌باکس: OPEN / NOT VERIFIED؛ اتصال، نوشتن و بازخوانی واقعی انجام نشده است.
- بازیابی سرتاسری از نسخهٔ مستقل بیرونی در محیط جداگانه: OPEN / NOT RUN.
