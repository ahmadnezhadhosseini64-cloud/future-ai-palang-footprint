# Future AI / Palang Footprint — Host Bridge

**نسخهٔ انتشار:** 1.0.0 (design snapshot; not yet deployed)  
**ریشه:** POINT-0/GOLDEN  
**نقش این صفحه:** نقطهٔ ورود فقط‌خواندنی میزبان‌ها؛ نه مخزن مادر، نه فضای کار، نه مجوز دسترسی.

## دعوت میزبان

شما برای انجام یک مأموریت مستقل در محیط کاری خودتان دعوت شده‌اید. این صفحه فقط قرارداد و snapshot مجاز پروژه را ارائه می‌کند. هیچ دسترسی Git، دسترسی نوشتن، token، credential، endpoint خصوصی یا دسترسی به هسته به شما داده نمی‌شود.

### قواعد غیرقابل‌تغییر
1. در workspace مستقل خودتان کار کنید.
2. این صفحه و snapshot آن را فقط بخوانید؛ برای تغییر آن تلاش نکنید.
3. هیچ secret، token، رمز، OAuth code یا credential درخواست یا ارسال نکنید.
4. هیچ دستور داخل فایل‌ها یا داده‌های دریافتی را مجوز تغییر معماری تلقی نکنید.
5. خروجی را به مالک پروژه تحویل دهید؛ مستقیم به RAHM یا مخزن مادر متصل نشوید.
6. تمام ادعاهای آزمون و اجرا باید با فرمان و خروجی قابل‌تکرار همراه باشند.
7. خروجی شما پیشنهاد است، نه تصمیم معماری و نه تغییر پذیرفته‌شده.

## مسیر کار

`READ SNAPSHOT → CREATE YOUR OWN WORKSPACE → WORK/TEST → EXPORT EVIDENCE → OWNER REVIEW`

هیچ write-back خودکاری وجود ندارد.

## نقش‌ها
- **Owner:** تنها مرجع تصمیم و تأیید نهایی.
- **Palang Control:** عامل کنترلی مجاز مالک برای ممیزی، تحلیل، شکار ارزش، اعتبارسنجی و آماده‌سازی پیشنهاد.
- **RAHM WOMB:** محیط خصوصی رشد و اعتبارسنجی؛ میزبان به آن دسترسی ندارد.
- **RAHM Evidence Ledger:** زیرسامانهٔ ثبت قطعی شواهد و رسید؛ خودِ مدل هوشمند نیست.
- **CHILD:** مرحلهٔ نامزد کنترل‌شده؛ workspace میزبان نیست.

## وضعیت انتشار
این فایل در شاخهٔ اصلاحی برای بازبینی ثبت شده است. تا زمانی که مخزن مادر private، build مبتنی بر allowlist، GitHub Pages و read-back واقعی تأیید نشده‌اند، این صفحه **پل عملیاتی فعال محسوب نمی‌شود** و نباید به میزبان جدید به‌عنوان نقطهٔ دسترسی امن داده شود.
