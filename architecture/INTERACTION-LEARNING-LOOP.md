# Interaction Learning Loop

- ID: ILL-2026-08-31-001
- Status: ACTIVE / LIVING / PERMANENT
- Reference: 0.0

## Canonical Loop
INTERACTION → OUTCOME → FEEDBACK → SUCCESS / FAILURE / MISUNDERSTANDING → LEARNING CANDIDATE → HYPOTHESIS → TEST → TRANSFER TEST → VALIDATION → KNOWLEDGE PROMOTION → REGISTRATION → EVIDENCE → RETRIEVAL → FUTURE INTERACTION

## Required Records
- Interaction context and goal
- Human intent and AI interpretation
- Uncertainty or ambiguity
- Observed outcome
- Human feedback/correction
- Failure or success pattern
- Learning candidate
- Test design and result
- Transfer context and result
- Evidence
- Validation state
- Promotion/registration decision

## Failure Learning
A failure is not automatically a limitation. Record whether it was a context failure, capability boundary, tool/integration boundary, misunderstanding, process failure, or verification failure. Test whether the corrected pattern transfers to a new context.

## Promotion Gate
A learning candidate remains experimental until it passes the applicable validation and transfer tests. Only then may it be promoted into durable project knowledge or a governed rule/principle.

## Inheritance
Validated knowledge inherits 0.0 and current Master governance. Experimental knowledge remains Child/Candidate until promoted.
