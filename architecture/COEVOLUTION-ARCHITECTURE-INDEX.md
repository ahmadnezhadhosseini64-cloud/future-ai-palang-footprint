## Canonical End-to-End Pattern
0.0 → Rule Inheritance → Human↔AI Interaction → Shared Understanding → Experiment/Outcome → Feedback → Learning Candidate → Test → Transfer/Regression → Validation → Knowledge Promotion → Registration → Provenance/Evidence → Persistence → Retrieval → Future Interaction → Evolution Record → repeat.

## Operational Control Plane
The architecture now explicitly includes four cross-cutting controls:
1. Formal State Machine: distinguishes lifecycle states and prevents unsupported state jumps.
2. Attempt Ledger: preserves every material attempt, result, failure class, evidence and next action under the same Stable ID lineage.
3. Execution-Proof Layer: separates specification, registration, retrieval, execution and outcome evidence.
4. Living Regression Governance: a successful run is a positive observation, not permanent immunity; regression remains open unless separately retired with evidence.

## Recovery Invariant
Incomplete ≠ Lost. Failed or incomplete artifacts remain addressable through Stable ID and provenance in Pending/Recovery. Future revival continues the same lineage and does not create a duplicate identity merely because an earlier attempt failed.

## Operating Rule
Every new meaningful interaction finding that is intended to improve the model should be classified into understanding, misunderstanding, learning candidate, experiment, transfer result, validated knowledge, or unresolved candidate. It should not be lost merely because it is not yet ready for Master promotion.

## Promotion Rule
Child/experimental discoveries do not automatically modify Master. Promotion requires stable identity, provenance, evidence, verification, and applicable change governance.

## Continuity Rule
The existing Archive Revival and Recovery architecture applies to historical discoveries; the Co-Evolution layer applies the same evidence discipline to future interaction learning.

## Architecture Intent
The project is therefore not only a memory/recovery system. It is a governed foundation for preserving interaction, testing understanding, learning from feedback and failure, validating transfer, and accumulating evidence about Human–AI co-evolution.
