## فارسی
هر یافته ارزشمند یا تولید نهایی‌نشده باید یا همان چرخه نهایی و Verify شود، یا با همان Stable ID / Production ID و Provenance در Revival Repository / Pending Queue باقی بماند. Pending گزارش صرف نیست؛ جایگاه معماریِ قابل ادامه است. در اجرای بعدی، همان رکورد Retrieve و از آخرین نقطه معتبر ادامه داده می‌شود، نه اینکه فقط دوباره کشف شود.

مسیر:
**FIND → VALIDATE → RECONCILE → [COMPLETE → REVIVE/ABSORB → ARCHITECTURAL PLACEMENT → REGISTER → READ-BACK → VERIFY → ACTIVE/LIVING] / [PENDING → PRESERVE → LATER RETRIEVE → RESUME]**

مسیر تاریخی نیز حفظ می‌شود تا ارتباط ایده/یافته با تصمیم و ساختمان معماری پروژه قابل ردیابی باشد.

## English
Every valuable finding or unfinished production must either complete the full verified path or remain preserved in the Revival Repository / Pending Queue with the same Stable ID / Production ID and provenance. Pending is not merely a report; it is a persistent architectural placement that can be resumed. On a later execution, the same record is retrieved and resumed from its last valid point rather than merely rediscovered.

Path:
**FIND → VALIDATE → RECONCILE → [COMPLETE → REVIVE/ABSORB → ARCHITECTURAL PLACEMENT → REGISTER → READ-BACK → VERIFY → ACTIVE/LIVING] / [PENDING → PRESERVE → LATER RETRIEVE → RESUME]**

Historical lineage is preserved so the relationship between an idea/finding, its rationale, and its architectural contribution remains traceable.

## Invariants
**INCOMPLETE ≠ LOST**
**PENDING ≠ BURIED**
**PENDING = PRESERVED + TRACEABLE + RESUMABLE**
**FOUND ≠ REPORT ONLY**
