## لنگر زمانی قطعی

1. مرجع اصلی زمان، زمان committer در commit ثبت‌شده در GitHub است؛ فیلد commit.committer.date با قالب ISO 8601 UTC و پسوند Z.
2. زمان UTC مبنای دائمی و تغییرناپذیر است. زمان Asia/Tehran صرفاً معادل محلیِ تبدیل‌شده است و باید با ذکر offset +03:30 نمایش داده شود.
3. زمان فعلی نقطهٔ صفر، زمان commit ایجادکنندهٔ همین سند است و باید از metadata همان commit در GitHub خوانده شود؛ از ساعت دستگاه یا زمان تقریبی استفاده نمی‌شود.
4. هر به‌روزرسانی بعدی، زمان commit جدید خود را دارد. آخرین commit معتبر روی main لنگر جاری پروژه است؛ تاریخ پایهٔ POINT-0 نیز برای همیشه در تاریخچه حفظ می‌شود.
5. اگر commit timestamp و author timestamp متفاوت باشند، برای زمان ثبت و لنگر اجرایی، committer timestamp ملاک است؛ author timestamp صرفاً فرادادهٔ منشأ است.
